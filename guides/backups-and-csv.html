Keep readable copies of your collection.

Back up, export and restore fragrances and notes through ordinary CSV files.

The working collection remains local to the computer.

Choose a local backup folder

  1. Choose a folder on first launch

    Or open Settings later to select or change it.

  2. Keep both generated files

    Scentkeep writes scentkeep-fragrances.csv and scentkeep-notes.csv.

  3. Let backups finish

    Each change refreshes both files in the background. An unfinished backup retries on the next launch. These files are refreshed copies, not a dated backup history; keep separate copies if you need older versions.

Export a CSV

Use Export CSV on the collection page for fragrances or on Perfume notes for the note catalogue. Exporting first gives you the correct template for editing in a spreadsheet.

In v0.2.4, fragrance exports contain 21 columns, including shelf, bottle counts, prices, concentration and ratings. Note exports contain name,image_url,parfumo_url,categories. Note-layer cells and categories use JSON arrays; ratings use a JSON object. Export a template instead of building these fields by hand. Older supported CSV formats can omit newer fields.

File format

Save edited files as UTF-8 CSV. Spreadsheet workbooks such as .xlsx and .xls are not supported.

Import or restore

  1. Open the matching page

    Use the collection page for fragrance CSV and Perfume notes for note CSV.

  2. Choose Import CSV

    Select a UTF-8 CSV exported by your version of Scentkeep. Keep its headers intact; column order may change.

  3. Review the result

    Scentkeep validates the entire file before saving. Duplicate fragrances and notes are skipped and listed.

Restore into a fresh collection

Import both files to restore fragrances and note metadata. Ordinary CSV import adds records and skips duplicates; it does not replace existing records or undo deletions. Export your current data before restoring.
