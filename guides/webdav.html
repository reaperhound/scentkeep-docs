Home/WebDAV

Back up through WebDAV.

Upload Scentkeep's two readable CSV files to an HTTPS folder you choose.

Use an existing HTTPS WebDAV folder with credentials that can read and write files. A provider-issued app password is recommended.

On this page
  1. Prepare the folder
  2. Connect
  3. After connecting

Prepare your WebDAV account

  1. Choose a folder

    Create or select an existing folder dedicated to Scentkeep backups.

  2. Copy its HTTPS URL

    Use the complete WebDAV folder address supplied by your provider.

  3. Create an app password

    Prefer a provider-issued app password over your main account password.

Connect from Scentkeep

  1. Open Settings

    Find WebDAV backup.

  2. Enter the connection details

    Provide the folder URL, username and app password.

  3. Choose Connect WebDAV

    Scentkeep checks the folder and stores the app password in your system keyring.

What happens next

After a fragrance or note changes, Scentkeep queues an upload of scentkeep-fragrances.csv and scentkeep-notes.csv. Rapid changes are combined into the latest backup. The files are refreshed copies, not a version history. CSV contents are readable by anyone with access to that folder; Scentkeep does not add end-to-end encryption.

If the folder already contains backups

Uploads pause until you open the collection page and choose Sync from WebDAV. Export any existing local data first, then sync before making changes. Both backup CSV files must be present.
