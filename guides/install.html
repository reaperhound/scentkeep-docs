Home/Install

Install Scentkeep.

Choose the release file for Windows, macOS or your Linux distribution.

Open the latest GitHub release before following the relevant steps.

On this page
  1. Windows
  2. macOS
  3. Linux
  4. Updates

Windows

  1. Download the EXE or MSI

    Choose either Windows installer from the latest release.

  2. Open the installer

    Follow its prompts. Windows may ask you to confirm the currently unsigned installer.

macOS

  1. Download the universal DMG

    The same build supports Intel and Apple silicon.

  2. Open the disk image

    Drag Scentkeep to Applications.

  3. Confirm the first launch

    macOS may ask you to approve the currently unsigned application.

Linux packages

Run the command for the file you downloaded from its directory.

Arch Linux

sudo pacman -U ./scentkeep-*.pkg.tar.zst

Debian or Ubuntu

sudo apt install ./scentkeep_*_amd64.deb

Fedora

sudo dnf install ./scentkeep-*.rpm

Other distributions

chmod +x ./scentkeep_*.AppImage

After making the AppImage executable, open it normally.

Check for updates

Use Check for updates inside Scentkeep. Windows, macOS and Linux AppImage builds can install a signed app update and restart. Distribution packages link back to the release page for the appropriate package.
