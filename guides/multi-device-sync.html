Home/Multi-device sync

Move between devices safely.

Use one WebDAV folder as the handoff point between Scentkeep installations.

This is deliberate CSV synchronization, not live collaborative editing.

On this page
  1. First device
  2. Next device
  3. Safe routine

Prepare the first device

  1. Connect WebDAV

    Point Scentkeep to the shared HTTPS folder.

  2. Make sure changes are saved

    Scentkeep queues the latest fragrance and note CSV files for upload.

  3. Wait for the backup

    Resolve any visible backup error before moving to another device.

Set up another device

  1. Install Scentkeep

    Open Scentkeep on the second device. Export any existing local fragrances and notes before syncing.

  2. Connect the same folder

    Use the identical WebDAV folder URL and account.

  3. Choose Sync from WebDAV

    Do this before adding or editing fragrances on the new device.

  4. Review the report

    Open the collection page and choose Sync from WebDAV. Scentkeep lists fragrances and notes added or updated.

A safe switching routine

Finish work on one device, let its backup upload, then sync on the next device before editing. Repeat that sequence whenever you switch.

Avoid overlapping edits

Do not edit the collection independently on two devices and assume real-time conflict resolution. Sync matches fragrances by brand and name and notes by name. Remote values overwrite matching local records, while local-only records remain. Deletions do not propagate, so deleted records can return from another device. Renaming a fragrance can create a separate record.
