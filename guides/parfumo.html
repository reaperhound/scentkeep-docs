Home/Parfumo

Connect Parfumo for note search.

Search Parfumo notes inside Scentkeep and save useful note metadata.

The connection is optional. Manual note entry remains available without it.

On this page
  1. Why connect
  2. Connect
  3. Use the connection
  4. Troubleshoot

Why connect Parfumo?

A saved Parfumo session lets Scentkeep search its note catalogue. Selecting a result can add the note name, image, categories and source link to your own catalogue.

Connect your account

  1. Open Settings

    Find the Parfumo account section.

  2. Choose Connect Parfumo

    Scentkeep opens Parfumo in a separate app window.

  3. Sign in on Parfumo

    Enter your credentials on Parfumo's site, not in Scentkeep.

  4. Save the session

    Return to Settings and choose Save session.

Where the session is kept

Scentkeep saves the site cookies in your operating system keyring. Disconnect removes the saved session.

Search and save notes

Open Perfume notes and enter at least two characters. Choose a Parfumo result to save it. Use Fill missing metadata to update existing notes where Parfumo has matching information.

If verification gets stuck

  1. Reset browser data

    Use the control in Settings, then open Parfumo and try again.

  2. Try another network

    If the Cloudflare challenge still loops, the embedded browser cannot force it to complete.

  3. Keep working manually

    You can always add perfume notes by name without a connection.
