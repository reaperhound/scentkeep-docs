Get to know your notes.

Build a note library with names, images and categories, then see how those notes shape each fragrance’s accords.

The note library is shared across your fragrance records.

On this page
  1. Build your library
  2. Set categories and images
  3. Rename or delete a note
  4. Understand main accords
  5. Keep your metadata

Build your library

  1. Open Perfume notes

    Choose Perfume notes in the sidebar. Enter a name and choose + Add note. Notes you add to a fragrance also become part of this catalogue.

  2. Find a saved note

    Use Search perfume notes to filter your library. Previous and Next appear when the results span multiple pages.

  3. Check where it is used

    Each card shows Used in … fragrances. This counts fragrance records using the note, rather than the number of times it appears across note layers.

Set categories and images

  1. Choose Edit categories

    Enter categories separated by commas, then choose Save categories. Categories supply the information used to estimate main accords.

  2. Add an image link

    Paste an image URL on the note card and choose + Add image link or Update image link. Remove image clears the picture while retaining the note.

  3. Bring in Parfumo metadata

    With a connected account, search and save Parfumo results, or choose Fill missing metadata for existing notes. A note can retain a View on Parfumo source link.

Read the Parfumo connection guide ↗

Rename or delete a note

Choose Rename on a note card, edit the name and Save. Renaming updates the note in your fragrance pyramids too.

Delete note asks for confirmation and removes the note from the library and all fragrances that use it. Use Remove image when you only want to clear its artwork.

Understand main accords

Open a fragrance record to see its Main accords. Scentkeep estimates relative strength from the categories assigned to its top, heart and base notes, and shows up to seven accords.

The strongest displayed accord is scaled to 100%; the others are relative to that strongest accord. These percentages do not represent ingredient quantities or a formula that adds up to 100%. Hover over an accord row to see its contributing notes.

If no accords appear

Add categories to the notes used in that fragrance, then reopen its record. Coverage depends on the saved categories; a note without useful category metadata may not contribute to the profile.

Keep your metadata

Use Import CSV and Export CSV on Perfume notes to move note names, image URLs, categories and source links. Keep this note CSV alongside your fragrance CSV when backing up the whole collection.
